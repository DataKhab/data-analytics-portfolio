# Построение бизнес-моделей AS IS и TO BE (Стекольный завод)

**Период:** 08.2024 — 02.2025
**Роль:** Ведущий бизнес-аналитик

## Краткое описание
Проведение глубокого обследования производственных и логистических процессов для выявления ключевых проблем и оценки финансовой ёмкости узких мест.

## Задача
Формализовать текущее состояние процессов (AS IS) и разработать целевую модель (TO BE), которая позволит оптимизировать производство и складскую логистику.

## Результаты
В ходе обследования было выявлено **167 проблемных зон** с общей финансовой ёмкостью **3,8 млрд рублей**. 
На основе модели AS IS была разработана дорожная карта решений и стратегические сессии. Внедрение предложенной модели TO BE позволило заложить основу для системной интеграции и автоматизации.

## Схемы
*   **[Модель AS IS](./diagrams/glass_as_is.svg)** — «Как есть сейчас». Детальное описание текущих процессов с указанием проблемных точек.
*   **[Модель TO BE](./diagrams/glass_to_be.svg)** — «Как должно быть». Целевая модель с оптимизированными процессами и предложенными изменениями.

## Технологии
*   **Нотация:** BPMN 2.0
*   **Инструмент:** Draw.io (экспорт в SVG с сохранением XML)
