# Описание данных

Использован датасет Food.com Recipes and Interactions (Kaggle):
https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-user-interactions

Файлы:
- recipes.zip.001 / .002 / .003 — разбитый 7-Zip архив с CSV-файлами:
  RAW_recipes.csv, RAW_interactions.csv, PP_recipes.csv, PP_users.csv,
  ingr_map.pkl, interactions_train.csv, interactions_test.csv,
  interactions_validation.csv.

Перед запуском ноутбука склеить и распаковать:
- Windows: правой кнопкой на recipes.zip.001 → 7-Zip → Extract Here.
