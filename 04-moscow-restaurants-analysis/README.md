Анализ рынка общественного питания города Москвы
О проекте
Данный проект представляет собой комплексное исследование рынка заведений общественного питания (кафе, рестораны, кофейни, бары и др.) города Москвы.

Цель исследования: Провести разведочный анализ данных (EDA) и дать обоснованные рекомендации по открытию нового заведения, а также выявить ключевые тренды рынка.

Задачи:

Загрузка и предобработка данных (очистка дубликатов, работа с пропусками).

Исследование распределения заведений по категориям и районам Москвы.

Анализ ценовых сегментов (средний чек, стоимость чашки кофе).

Анализ рейтингов заведений и влияния на них различных факторов (сеть/не сеть, круглосуточная работа).

Визуализация данных на интерактивных картах (Folium).

Разработка рекомендаций для бизнеса.

Инструменты и стек технологий
Проект реализован с использованием следующего программного обеспечения:

Язык программирования: Python 3.x

Среда разработки: VS Code, Jupyter Notebook

Библиотеки анализа данных: Pandas, NumPy

Визуализация: Matplotlib, Seaborn, Plotly, Folium

Работа с СУБД: DuckDB, DBeaver (запросы SQL для агрегации данных)

BI-инструменты: Power BI, Looker Studio (Google Data Studio)

Контроль версий: Git, GitHub

Структура проекта
Nootebooks/ — содержит основной Jupyter Notebook (restoran.ipynb) с кодом исследования.

data/ — папка с исходным датасетом moscow_places.csv.

requirements.txt — файл зависимостей для установки окружения.

Основные результаты и рекомендации
1. Самое большое количество столовых, как не удивительно, в центре. меньше всего их на на юго-западе. В данном случае чуствуется явный дефецит такого рода заведений в ЮЗАО.
2. Очень мало круглосуточных столовых в районах кроме центрального  и северо-востока столицы.

Выявлены районы с наибольшей концентрацией заведений (Центральный АО) и районы с низкой конкуренцией.

Определены средние показатели рейтинга и цен для успешного позиционирования.

Построены интерактивные карты для визуализации гео-распределения.

Как запустить проект
Склонируйте репозиторий:

bash
git clone https://github.com/DataKhab/restoran_analysis.git
Установите зависимости:

bash
pip install -r requirements.txt
Откройте проект в VS Code и запустите файл Nootebooks/restoran.ipynb.
Примечание: Пути к данным в ноутбуке настроены относительно корня проекта (../data/moscow_places.csv).

Визуализация и Дашборды
Результаты анализа визуализированы в интерактивных дашбордах.

Для работы с Looker Studio данные из ноутбука выгружались на Google Диск (в формате CSV/Google Sheets) для последующей загрузки в отчет.

Для работы с Power BI использовались выгрузки данных, сформированные по результатам анализа.
