На этих дашбордах были приведены проанализированные в работе данные. Для наглядности были собраны в двух дашбордах. Соотношение категорий заведений показывает, что львиную долю рынка занимают кафе (28,3%), рестораны (24,3%) и кофейни (16,8%), очень слабо представлены булочные и столовые. Количество посадочных мест сильно зависит от категории заведений. Всего 8,7% заведений Москвы работает круглосуточно. Рейтинг заведений различается по категориям заведений. Также заметно значительное различие среднего счета заведений в зависимости от их распределения по округам и категории заведения.
