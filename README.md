## 🚀 Проекты

### 1. Анализ цен на бриллианты (01-diamonds-price-analysis)
**Цель:** Изучить факторы, влияющие на стоимость бриллиантов, и построить модель для прогнозирования цены.
*   **Инструменты:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn.
*   **Данные:** Датасет `DiamondsPrices2022.csv`.
*   **Результат:** Выявлены ключевые характеристики (карат, огранка, чистота), влияющие на цену. Построена и оценена модель регрессии.
*   [Подробнее в папке проекта](./01-diamonds-price-analysis/README.md)

### 2. Анализ заведений Москвы (02-moscow-restaurants-analysis)
**Цель:** Проанализировать рынок общепита Москвы для выявления популярных категорий и районов.
*   **Инструменты:** Python, Pandas, Plotly, GeoPandas.
*   **Данные:** `moscow_places.csv`.
*   **Результат:** Сформированы рекомендации по открытию новых заведений на основе плотности и конкуренции.
*   [Подробнее в папке проекта](./02-moscow-restaurants-analysis/README.md)

### 3. Бизнес-моделирование (03-business-modeling-projects)
**Цель:** Описание и оптимизация бизнес-процессов для повышения эффективности.
*   **Инструменты:** BPMN,Draw IO, ARIS, MS Visio.
*   **Содержание:** Модели "AS-IS" и "TO-BE" для логистики и производства.
*   **Файлы:** `BSZ_AS-IS_TO-BE_Model.pdf`, `KUDO_AS-IS_Model.pdf`.
*   [Подробнее в папке проекта](./03-business-modeling-projects/README.md)

### 4. Система рекомендаций рецептов (04-recipe-recommendation-system)
**Цель:** Создать алгоритм, который предлагает рецепты на основе имеющихся ингредиентов и предпочтений пользователя.
*   **Инструменты:** Python, NLP, Collaborative Filtering.
*   **Результат:** Прототип рекомендательной системы.
*   [Подробнее в папке проекта](./04-recipe-recommendation-system/README.md)
